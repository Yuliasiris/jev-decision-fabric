# Security

Credentials belong in the deployment environment. Do not commit API keys,
JEV_AUTH_CONFIG values, session or grant tokens, activation links, probe values
or temporary encrypted handoffs. The example configuration contains no usable
credentials. The source's fixed issuer and same-origin checks are preserved.

Both MCP tools require the existing OAuth authorization. Input text does not
grant new scope or select a destination. Each provider call consumes the
existing inference quota. Do not silently retry paid calls.

The service returns advisory results and never applies or dispatches actions.
Public trace inspection is not provided. A private trace finish readback does
not imply that source documents or a resumable workspace were stored.

Use the maintainer's private reporting route associated with the actual
distribution. Until a public source location and reporting route are confirmed,
do not publish vulnerability details containing secrets in a public issue.
No invented reporting address or unverified support URL is supplied here.
